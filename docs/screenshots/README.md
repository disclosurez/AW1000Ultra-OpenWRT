# Screenshots

Every screenshot uses the **interactive demo's fictional data**. No router,
client, credential or live identifier is contacted or captured.

The console images are generated from the current demo with the demo-only
badge, banner and mock notes hidden. `captive-portal-splash.png` is rendered
from the current `portal/splash` CGI with example values, so it shows the real
guest page.

| File | What it shows |
|---|---|
| `overview.png` | Overview dashboard, desktop |
| `overview-mobile.png` | Overview dashboard on a phone viewport |
| `captive-portal-local.png` | **Wireless → Captive Portal** settings |
| `captive-portal-splash.png` | The guest splash/terms page with one-tap **Accept & continue** |
| `parental-devices.png` | **Parental Control → Devices & Activity** with **All / LAN / Guest Wi-Fi** scopes |
| `guest-wireless-devices.png` | **Guest Wireless → Devices** with Block/Unblock |
| `guest-wireless-logs.png` | **Guest Wireless → Logs** with IP, MAC and vendor |
| `dns-log.png` | **Logs → DNS Log** with per-device history and categories |
| `siem.png` | **Services → SIEM Forwarding** |
| `tools-webview.png` | **Tools → Web Viewer** |
| `tools-fileshares.png` | **Tools → File Shares** and the router drop box |
| `tools-opencode.png` | **Tools → OpenCode**, Status tab |
| `system-leds.png` | **System → LED Configuration** |
| `statistics-graphs.png` | **Statistics → Graphs** with load, CPU, memory and interface meters |
| `status-firewall.png` | **Status → Firewall** chains and zone policies |
| `vendor-services.png` | **Services → Vendor Services**, the other vendor firmware service pages |
| `lock-band.png` | **Sim Modem → Lock Band**, band selection and radio state |
| `system-log.png` | **Logs → System Log**, logd ring buffer |
| `processes.png` | **Logs → Processes**, custom `top`-style process list |

All addresses use documentation ranges (`192.168.1.0/24`,
`192.168.5.0/24`, `203.0.113.0/24`), all MACs use the locally administered
`02:00:00:00:00:xx` range, and every SSID/hostname is an example value.
